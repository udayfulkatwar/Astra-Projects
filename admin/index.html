    GitHub key for switching off

    Switching links off, and opening this page on your other devices with the passphrase alone, need a GitHub key, saved once on any one device. Make a fine-grained token and paste it here. It is stored locked with your owner key.

    1. Open GitHub's new-token page (name, one-year expiry and Contents: Read and write are filled in).
    2. Under Repository access choose Only select repositories → astra-projects.
    3. Press Generate token, copy it, paste it below and press Save key.
